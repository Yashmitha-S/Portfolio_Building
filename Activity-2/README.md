# Activity 1: C/C++ Development Environment Setup

## Objective
To configure a C/C++ development environment using Visual Studio Code and successfully execute a C program.

## Tools Used
- Visual Studio Code (VS Code)
- Microsoft C/C++ Extension
- Apple Clang C Compiler
- macOS Terminal

## Implementation
Configured the development environment on macOS and verified the C compiler.
Created a `hello.c` program using the C programming language.
Compiled the program using the Clang compiler.
Successfully executed the program and verified the output: `Hello, World!`

## Result
The C development environment was successfully configured, and the Hello World program executed without errors.
